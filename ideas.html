相図とは何か・記号で導く λ = σ ± iω・大事な8つの発想

特定の数値問題の暗記ではなく、どんな式が来ても一般記号（x, v, J, τ, Δ, λ, σ, ω）でそのまま道筋を立てられるように整理しました。

1. 相図とは何か 2. λ = σ ± iω への変換手順 3. 大事な8つの発想と初手 4. 記号チェック（10問）

STEP 1そもそも「相図（位相平面）」とは何か？

定義: 時間 t を消去し、横軸に「状態 x」、縦軸に「変化率 v = dx/dt」をとって、「今 (x, v) にいる点はこの先どちらへ動くか」を矢印と軌道で描いた地図のこと。

時系列グラフ (t, x(t)) は「1つの初期値から時間が経つとどうなるか」しか分かりません。相図 (x, v) にすると、すべての初期値に対する未来の動き（収束するか・回り続けるか・発散するか）が1枚の図で一望できるのが最大の強みです。

図1: 時系列グラフの減衰振動（左）と、同じ現象を状態空間に描いた相図（右）の対応
1. 固定点（平衡点）x* dx/dt = 0 かつ dv/dt = 0 となる静止点。相図では漸近安定なら 黒丸、不安定なら 白丸 で描く。
2. 回転の向き（なぜ必ず時計回りか） 横軸 x・縦軸 v = dx/dt なら、上半分（v > 0）では x が増える右向き、下半分（v < 0）では左向きになるため 必ず時計回り になる。
3. 固有ベクトルと直線軌道 λ > 0 の固有ベクトル上は固定点から 外向き（離れる）、λ < 0 上は 内向き（近づく）の矢印になる。
4. セパラトリクス（境界線） 「収束する領域」と「発散・接触・回転する領域」を分ける境目の軌道。鞍点の安定多様体がこれを形成する。

STEP 2どんな式も記号のまま λ = σ ± iω に変える 6ステップ手順

Step 1

2階以上の式を「1階連立微分方程式」にする

状態変数 x1 = x、x2 = dx/dt と置いて、最高階微分について解く。

dx1/dt = f1(x1, x2) = x2 dx2/dt = f2(x1, x2)
Step 2

固定点 x* = (x1*, x2*) を求める

f1(x1*, x2*) = 0 かつ f2(x1*, x2*) = 0 => x2* = 0 と f2(x1*, 0) = 0
Step 3

固定点まわりの偏微分でヤコビ行列 J(x*) を作る

微小ずれ δx = x - x* の線形近似 d(δx)/dt = J(x*) δx を得る。力学系（f1 = x2）なら1行目は常に [0, 1]。

J(x*) = [ [ df1/dx1 , df1/dx2 ], [ df2/dx1 , df2/dx2 ] ]_{x = x*} = [ [ 0 , 1 ], [ a , b ] ]
Step 4

τ = tr(J) と Δ = det(J) から特性方程式を立てる

τ = tr(J) = J11 + J22 = λ1 + λ2 (対角成分の和 = 固有値の和) Δ = det(J) = J11*J22 - J12*J21 = λ1*λ2 (行列式 = 固有値の積) 特性方程式: det(J - λI) = λ^2 - τ*λ + Δ = 0
Step 5

解の公式で λ を出し、実部 σ と虚部 ω に分ける（ここが本質）

λ = ( τ ± sqrt(τ^2 - 4*Δ) ) / 2 [場合A] τ^2 - 4*Δ >= 0 のとき（実固有値 λ1, λ2、虚部 ω = 0）: 解の形: δx(t) = c1 * exp(λ1*t) * w1 + c2 * exp(λ2*t) * w2 (回らず直線・双曲線で動く) [場合B] τ^2 - 4*Δ < 0 のとき（複素固有値 λ = σ ± i*ω）: 実部: σ = Re(λ) = τ / 2 虚部: ω = Im(λ) = sqrt(4*Δ - τ^2) / 2 オイラーの公式より: exp((σ + i*ω)*t) = exp(σ*t) * (cos(ω*t) + i*sin(ω*t))
  • 実部 σ = τ/2 の意味: 振幅 exp(σ*t) の増減を決める。σ < 0 で減衰して収束（安定）、σ = 0 で大きさ一定（中心点）、σ > 0 で拡大して発散（不安定）。
  • 虚部 ω の意味: cos(ω*t) による回転（振動）の速さを決める。ω != 0 なら必ず渦や円を描いて回る。
Step 6

固有ベクトル w を求める（実固有値のときの直線の向き）

(J - λI) w = 0 特に J の1行目が [0, 1] なら 1行目は - λ*w1 + w2 = 0 => w = (1, λ)^T (傾きがそのまま λ)
図2: 固有値の実部・虚部 (σ, ω)（左）と、トレース・行列式 (τ, Δ) 平面（右）の完全な対応関係

STEP 3記号で見る「大事な8つの発想」と初手マップ

問題文のキーワード 最初に取るべき発想 1行目に書く一般記号・式
「モデル化」「省く理由」 目的に対して必要十分な要素だけ残す 状態変数とパラメータを目的に応じて最小限に絞る
「誤差の種類」「頭打ち」 数の表し方（丸め）と計算の打ち切りを分ける 近い数の減算（桁落ち）は式変形で回避。大+小（情報落ち）に注意
「刻み幅 dt」「発散条件」 1ステップ誤差と積算誤差の区別、増幅率の絶対値 陽解法: |1 + k*dt| <= 1 / 陰解法: x_{n+1} = x_n/(1 - k*dt)
「高階ODE」「数値計算」 補助変数を置いて1階連立系へ統一する x1 = x, x2 = x' とし、RK4は全成分を同じ段階で揃えて進める
「妥当性検証」「バグ確認」 見た目の滑らかさではなく保存則と次数傾きで確認 保存量 |E(t)-E(0)| の両対数傾きが理論次数 p と一致するか見る
「固定点」「ヤコビアン」「相図」 近傍は J, τ, Δ, σ, ω で線形判定、遠方は非線形相図 dx/dt=0 -> J -> λ = σ ± iω。σ=0 や Δ=0 は線形化判定不可
「安定化制御」「臨界減衰」 フィードバックで σ < 0（左半平面）へ移動する τ = -kd < 0, Δ = kp - g/l > 0、臨界条件 τ^2 = 4*Δ
「求根」「消去法」「LU分解」 接線で追い込み、連立1次方程式は分解再利用とピボット J*δ = -f（マイナス必須）。LU分解 O(n^3) + 前・後退代入 O(n^2)

発想1 [モデル化]：現実に忠実なほど良いのではなく「目的に必要十分」が最善

  • 複雑にするほど計算コスト増・未知パラメータ増・誤差原因の切り分け困難・制御設計の複雑化を招く。

発想2 [数値誤差]：有限桁（float32 約7桁 / float64 約16桁）を前提に式を組む

  • 丸め誤差（有限桁の限界）vs 打ち切り誤差（有限項・有限 dt の限界）。
  • 情報落ち（大きい数 + 小さい数で小さい方が消える）vs 桁落ち（近い数の引き算で有効桁が失われる）。解と係数の関係 x1 = c/(a*x2) や有理化で引き算を消す。

発想3 [時間発展]：1ステップ O(dt^(p+1)) と積算 O(dt^p)、安定性とコストの天秤

  • 一定時間 T を進むと T/dt ステップ積むため、積算誤差は1ステップより次数が1つ下がる。
  • 前進オイラー（陽解法）は条件安定 |1+k*dt| <= 1、後退オイラー（陰解法）は次時刻の式を解くことで k < 0 で無条件安定。RK4は4点評価の重み平均 (k1+2k2+2k3+k4)/6 で4次精度を稼ぐ。
  • dt を小さくしすぎると打ち切り誤差より丸め誤差の蓄積が勝ち、精度が頭打ちになる。

発想4 [1階連立化]：どんな高階微分方程式も1階ベクトル dx/dt = f(t, x) に統一

  • 状態変数 x1 = x, x2 = x' と置けば、スカラー用に組んだ数値積分アルゴリズムをそのまま流用できる。
  • 多変数のRK4では各段階 k1 -> k2 -> k3 -> k4 で全成分を同じ時刻・同じ中間状態に揃えて評価する。

発想5 [妥当性検証]：見た目がそれらしいだけではダメ。保存則と理論次数で検証する

  • 解析解がない非線形系でも、dt 縮小による収束確認や、保存量（エネルギー E）の誤差 |E(t)-E(0)| の両対数傾きが手法の次数 p に一致するかでバグを検出できる。

発想6 [固定点と相図]：局所は固有値 λ = σ ± iω、大域は非線形相図

  • 固定点近傍だけヤコビアン J(x*) で線形化すれば σ = Re(λ) の符号で安定・不安定が分かる。
  • ただし σ = 0（中心点・分岐点 Δ=0）では高次項が効くため線形化だけでは判定不可。遠方の境界（セパラトリクス）や周期変数の同一性（θ = π と -π）も相図で把握する。

発想7 [安定化制御]：フィードバックで系の固有値を左半平面（σ < 0）へ移す

  • 復元力ゲイン kp と減衰ゲイン kd を加え、特性方程式の係数から τ < 0, Δ > 0 に配置する。臨界減衰 τ^2 = 4*Δ がオーバーシュートなしの最速収束条件。

発想8 [求根と線形代数]：ニュートン法は J*δ = -f、線形計算はピボットと分解再利用

  • ニュートン法は接線で近似解を更新するが、f'(x)=0（det J = 0）で停止し、初期値によっては2周期振動で収束しない。
  • ガウス消去法の部分ピボットは「0除算回避」と「微小値除算による丸め誤差拡大の防止」。LU分解は A=LU（O(n^3)）を1回作り、別の右辺 b に対して O(n^2) の前進・後退代入を再利用する。inv(A)@b は約3倍の演算量と誤差増を招くため使わない。
