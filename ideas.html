「モデル化せよ」「要素を省く理由」 目的に対して必要十分な複雑さだけ残す 目的（速度 / 姿勢 / 着地）に不要な要素を削る判断と弊害を書く
「誤差の種類」「float32 で頭打ち」 有限桁表現と丸め・打ち切り・桁落ち・情報落ちを分ける 近い数の減算は式変形で回避（解と係数・有理化）、大+小の吸収は情報落ち
「刻み幅 dt」「精度次数」「発散しない条件」 1ステップ誤差と積算誤差の区別、増幅率の絶対値 前進オイラーは |1 + k*dt| <= 1、RK4は4点重み平均 (1,2,2,1)/6
「2階微分方程式」「プログラムに直せ」 状態変数を増やして1階連立へ統一する x1=x, x2=x' と置き、最高階について解く（m や ml^2 で割る）
「妥当性を検証せよ」「バグがない根拠」 グラフの滑らかさではなく独立した保存則・次数で確かめる エネルギー保存誤差 |E(t)-E(0)| の両対数傾き（1次/4次）と dt 収束
「固定点」「ヤコビアン」「相図」 近傍は線形化（tau, Delta）、境界・遠方は非線形相図で見る dx/dt=0 で固定点 -> J -> Delta, tau, tau^2-4*Delta。ただし Re=0 は判定不可
「安定化制御」「臨界減衰ゲイン」 制御入力で固有値（極）を左半平面へ動かす 線形化して tau = -kd < 0, Delta = kp - g/l > 0、臨界は tau^2 = 4*Delta
「ニュートン法」「ピボット」「LU分解」 接線で反復更新、連立方程式はピボット・分解再利用・solve優先 J*delta = -f（マイナス必須）、LUは前・後退代入で O(n^2)、逆行列は使わない

STEP 2シミュレーション工学の大事な8つの発想

発想 1

モデル化：現実を全部入れず「目的に必要十分」を残す

コア発想: 複雑なモデルが良いモデルとは限らない。目的に効く要素だけを選び、他を削ぎ落とす。
  • なぜ大事か: 要素を増やすほど計算コスト増・調整パラメータ増・誤差原因の不明瞭化・制御設計の困難化を招く。
  • 具体例: 落下速度だけ知りたいなら「質点」、姿勢変化なら「剛体」、着地後の跳ね返りなら「条件分岐付きのバネ反力」を追加する。
発想 2

数値誤差：計算機の有限桁を意識し、近い数の引き算を避ける

コア発想: コンピュータは単精度 約7桁・倍精度 約16桁の有限桁しか持たないため、式の書き方ひとつで精度が崩れる。
  • 4分類の軸: 「数の表し方」が原因なのが 丸め誤差、「計算の打ち切り」が原因なのが 打ち切り誤差。
  • 2つの落とし穴: 「大きい数 + 小さい数」で小さい側が消えるのが 情報落ち、「近い数 - 近い数」で有効桁が減るのが 桁落ち。
  • 回避の発想: 2次方程式では大きい解だけ公式で出し、小さい解は解と係数の関係 x1 = c/(a*x2) で引き算を消す。
発想 3

時間発展：1ステップ誤差と積算誤差、陽解法と陰解法のトレードオフ

コア発想: 微分方程式を小さな刻み dt で進める際、「安定性」と「精度あたりの計算コスト」を天秤にかける。
  • 安定条件の意味: 前進オイラー法（陽解法）は |1 + k*dt| <= 1 を超えると振動発散する。後退オイラー法（陰解法）は次時刻の式を解く手間と引き換えに k < 0 で無条件安定になる。
  • なぜ RK4 がよく使われるか: 1ステップの関数評価は4回と重いが、4次精度 O(dt^4) のため大きな dt でも高精度が出せ、目標誤差までの総評価回数が圧倒的に少ない。
  • 刻み幅過小の罠: dt を極端に小さくしすぎると打ち切り誤差より丸め誤差の蓄積が支配的になり、誤差が頭打ちになる。
発想 4

1階連立化：すべての高階ODEを「1階ベクトル系」に揃えて同じ道具で解く

コア発想: 位置と速度を並べた状態ベクトルを置けば、2階も3階もすべて同じ1階ソルバ（オイラー・RK4）に流し込める。
  • 手順: 最高階微分を左辺に孤立させ（例: m や慣性モーメント m*l^2 で割る）、補助変数を定義する。
  • 実装の鉄則: 多変数のRK4では、各段階（k1 -> k2 -> k3 -> k4）ごとに 全成分を同時に揃えて評価 する。ある成分だけ先に更新すると半陰解法など別の手法になる。
発想 5

妥当性検証：見た目ではなく「物理保存則」と「理論次数」でバグを炙り出す

コア発想: グラフがそれらしく見えるだけでは正しいと言えない。方程式から独立に成り立つ不変量と収束次数で確認する。
  • 解析解がある場合: 真値との誤差を両対数グラフに描き、傾きが理論次数（オイラー1, ホイン2, RK4 4）に一致するか見る。
  • 解析解がない非線形系: dt を半分ずつ減らして結果の収束を確認し、減衰なし単振り子なら 力学的エネルギー保存 |E(t) - E(0)| の傾き（次数）を確認する。
発想 6

固定点と線形化：近傍の「戻る・離れる・回る」は固有値で、境界と遠方は相図で読む

コア発想: 非線形系は式が解けなくても、固定点まわりのヤコビアン J を調べれば局所的な安定性と相図の形が決まる。
  • 判定の3手: Delta < 0 なら即「鞍点（不安定）」。Delta > 0 なら tau の符号で安定/不安定/中心点を決め、tau^2 - 4*Delta の符号で渦状点と結節点を分ける。
  • 線形化の限界: Re(lambda) = 0（中心点や分岐点 Delta = 0）では高次項が効くため 線形化だけでは安定性を判定できない。また吸引領域の境界（セパラトリクス）や大車輪回転のような大域挙動は非線形相図で確認する。
発想 7

制御設計：不安定な固定点の固有値を、フィードバックで左半平面へ移す

コア発想: 倒立状態のような不安定点でも、ずれに比例する復元力 (P) と速度を抑えるブレーキ (D) を足せば安定にできる。
  • 線形化と極配置: 倒立振り子では重力項の符号が真上基準で + になる。これに負のフィードバックを入れ、tau = -kd < 0 かつ Delta = kp - g/l > 0 を満たすようにゲインを選ぶ。
  • 現実・離散の制約: 臨界減衰 tau^2 = 4*Delta はオーバーシュートなしで最速収束する基準。ただし離散制御でゲインを大きくしすぎると1ステップ変化が過大になり数値発散する。
発想 8

求根と線形代数：接線で追い込み、連立方程式は「分解の再利用」と「ピボット」で安定・高速に解く

コア発想: 非線形方程式はニュートン法（線形方程式の反復）に落とし、線形方程式は直接逆行列を作らずピボット付き消去・LU分解を使う。
  • ニュートン法の罠: J*delta = -f（マイナス符号必須）。f'(x)=0 や det J=0 でゼロ除算停止するほか、初期値によっては2点間を往復する周期解に入り収束しない。
  • ピボット選択と LU 分解: 部分ピボットは「0除算回避」と「微小値で割る丸め誤差拡大の防止」のため。右辺 b だけ何度も変わる場合は O(n^3) の LU 分解を1回し、O(n^2) の前進・後退代入を再利用する。inv(A)@b は約3倍遅く誤差も増えるため使わない。
