PART 1 (試験配点の中心)演習1「単振り子の運動」レポート (1)-(8) まとめ

演習1 (1)-(2)

運動方程式の導出と1階連立化・エネルギー保存

m * l * theta'' = -m * g * sin(theta) => theta'' = -(g/l) * sin(theta) d(theta)/dt = omega, d(omega)/dt = -(g/l) * sin(theta)
  • 試験のツボ: 両辺を ml（または回転方程式 ml^2 * theta'' = -mgl sin(theta) を ml^2）で割ると質量 m が消え、動きは質量に依存しない（ただしエネルギー E = 0.5*m*l^2*omega^2 + m*g*l*(1 - cos(theta)) の計算には m を使う）。
演習1 (3)-(4)

オイラー法とRK4の比較（なぜ振幅が膨らむか）

前進オイラー: theta[n+1] = theta[n] + dt*omega[n], omega[n+1] = omega[n] - dt*(g/l)*sin(theta[n]) RK4(2変数): 各段階 k1 -> k2 -> k3 -> k4 ごとに theta と omega をペアで同時に進めて評価する
  • オイラー法の結果と考察: 刻み幅 dt が大きいと前進オイラー法は 力学的エネルギーを人工的に増やす ため、相図が閉じた円にならず外へ膨らみ振幅が増大する。dt = 0.01 -> 0.001 -> 0.0001 と細かくすると真値へ近づく。
  • RK4の考察: dt = 0.01, 0.001, 0.0001 で曲線がほぼ重なるが、曲線が一致するだけでは式自体のバグがない証明にならないため、次の (5) で独立した物理保存則を確認する。
演習1 (5)-(6)

プログラムの妥当性評価と精度の次数

  • 妥当性評価: 減衰なし単振り子では力学的エネルギー E が一定に保たれる。そこでエネルギー保存誤差 |E(t) - E(0)| を両対数グラフに描き、傾きがオイラー法で 1（1次精度 O(dt)）、RK4で 4（4次精度 O(dt^4)）になることを確認すれば実装の強い根拠になる。
  • 誤差次数の区別: オイラー法のテイラー展開より、1ステップの局所打ち切り誤差は O(dt^2)、一定時間 T（T/dt ステップ）の積算（大域）誤差は O(dt)。
演習1 (7)

相図と6つの初期条件の解釈

初期条件 (theta0, omega0)運動と相図上の軌道物理的ポイント
(0, 0)最下点で静止（固定点・中心点）ヤコビ固有値 +-i*sqrt(g/l)、中立安定（漸近安定ではない）
(pi/2, 0)行って戻る往復振動（閉軌道）エネルギー E = mgl < 2mgl。非線形系なので周期は振幅に依存
(pi, 0) と (-pi, 0)真上の不安定平衡点（鞍点・同一の点）2*pi 周期で同一姿勢。数値上は sin(pi)!=0 の丸め誤差でも落下する
(-pi, 1) / (pi, -1)上下の帯状の連続回転（大車輪）真上で速度を持つため E > 2mgl（位置エネルギー障壁越え）
  • セパラトリクス: (+-pi, 0) を通る軌道が「振動（閉軌道）」と「回転（上下の帯）」を分ける境界線になる。
演習1 (8) 発展

倒立状態の安定化制御

  • 真上（phi = 0）基準の座標にすると重力項の符号は +(g/l)*sin(phi) に変わる。
  • 重力補償＋PD制御（または線形倒立振り子のPD制御 u = -kp*phi - kd*omega）により、tau = -kd < 0, Delta = kp - g/l > 0（kd > 0, kp > g/l）を満たせば上死点近傍で漸近安定化できる。ただし局所安定化であり、トルク飽和やセンサノイズには注意が必要。

演習2 (1)-(2)

無次元運動方程式・固定点条件・ニュートン法

z' = v, v' = -beta*v - z + alpha/(1 - z)^2 (0 <= z < 1) 固定点条件: v = 0, alpha = z*(1 - z)^2 ニュートン法: f(z) = alpha - z*(1 - z)^2, f'(z) = (1 - z)*(3*z - 1)
  • alpha = 36/343 での2つの物理的固定点は z* = 1/7（初期値 0.1 から収束）と z* = 4/7（初期値 0.6 から収束）。
  • 失敗する初期値: z0 = 1/3（山の頂上）および z0 = 1 では f'(z0) = 0 で接線が水平・分母 0 となり更新停止。z0 > 1 は範囲外の根 9/7 に収束する。
演習2 (3)-(5)

ヤコビアン・相図手描きと物理的解釈

  • 固定点 (1/7, 0)（beta = 1）: J = [[0, 1], [-2/3, -1]]。tau = -1, Delta = 2/3, tau^2 - 4*Delta = -5/3 < 0 より 安定渦状点（黒丸・時計回り）。なお beta = 2 に強めると tau^2 - 4*Delta = 4/3 > 0 となり 安定結節点 へ変わる。
  • 固定点 (4/7, 0): J = [[0, 1], [5/3, -1]]。Delta = -5/3 < 0 より 鞍点（不安定・白丸）。固有ベクトルは w = (1, lambda)^T（正の固有値 approx +0.88 は外向き、負 approx -1.88 は内向き）。
  • 物理的理由: ばね力 z の増え方と静電力 alpha/(1-z)^2 の増え方を比べると、1/7 ではばねの増加率が勝って押し戻す（安定）、4/7 では静電力の増加率が勝って引き込まれ電極接触（プルイン）する。初期値 (0, 0.5) は 1/7 へ収束し、(0, 0.8) はセパラトリクスを越えて接触する。
演習2 (6)-(7)

サドルノード分岐と電圧フィードバック制御

  • サドルノード分岐: g(z) = z(1-z)^2 は z = 1/3 で極大値 alpha = 4/27 をとる。0 < alpha < 4/27 で2個、alpha = 4/27 で1個（固有値 0, -1：線形化だけでは判定不可・半安定）、alpha > 4/27 で固定点 0 個となり全初期値から必ず接触する。
  • 電圧PD制御: alpha は印加電圧の2乗（V^2）に比例するため負にできない。よって alpha(z, v) = max(0, alpha_ff - Kp*(z - z_ref) - Kd*v) と 0 でクリップして z_ref > 1/3 の位置も安定化する。
