PART 1 (試験配点の中心)演習1「単振り子の運動」レポート (1)-(8) 記号まとめ

演習1 (1)-(2)

運動方程式・1階連立化・保存量 E

回転の運動方程式: m * l^2 * θ'' = -m * g * l * sin(θ) => θ'' = -(g/l) * sin(θ) 1階連立形: dθ/dt = ω, dω/dt = -(g/l) * sin(θ) 力学的エネルギー: E(θ, ω) = (1/2) * m * l^2 * ω^2 + m * g * l * (1 - cos(θ))
  • 記号の本質: 運動方程式を整理すると質量 m が約分されて消えるため、角度・角速度の動きは m に依存しない（エネルギー E を計算するときだけ m を使う）。
演習1 (3)-(6)

オイラー法・RK4の挙動と妥当性評価・精度次数

前進オイラー: θ[n+1] = θ[n] + dt * ω[n], ω[n+1] = ω[n] - dt * (g/l) * sin(θ[n]) RK4(2変数): 各段階 (k1, k2, k3, k4) で θ と ω の両方を同じ中間段階に揃えて評価する 誤差次数: 1ステップ局所誤差 O(dt^(p+1)) => 一定時間 T 後の積算誤差 O(dt^p)
  • オイラー法で振幅が増える理由: 減衰のない単振動・振り子に前進オイラー法を使うと、1ステップごとの増幅率の大きさが 1 をわずかに上回り、力学的エネルギーを人工的に増やし続けるため、相図が閉じた輪にならず外へ膨らむ。
  • 妥当性評価の核心: 刻み幅 dt を細かくして曲線が重なるだけでは「式自体の間違い」を見抜けない。そこで微分方程式から独立に導かれる 力学的エネルギー保存 を使い、|E(t) - E(0)| の両対数グラフの傾きが理論次数 p（オイラー 1、RK4 4）に一致することでプログラムの正しさを裏付ける。
演習1 (7)

相図 (θ, ω) の構造と周期境界

  • 2つの固定点: θ* = 0（最下点）はヤコビアン J = [[0, 1], [-g/l, 0]] より固有値 λ = ±i*sqrt(g/l)（実部 σ = 0 の純虚数）＝ 中心点（中立安定・閉軌道）。θ* = π（真上）は J = [[0, 1], [+g/l, 0]] より固有値 λ = ±sqrt(g/l) ＝ 鞍点（不安定）。
  • 周期性の注意: θ は 2π 周期の変数なので、θ = π と θ = -π は物理的に 同一の固定点（真上） である。
  • 振動と回転を分ける境界（セパラトリクス）: 真上の静止エネルギー障壁 E = 2*m*g*l より小さい初期値（例: 途中で止まる）は中心点周りを回る 往復振動（閉軌道）、障壁 2*m*g*l を超える初期値（真上で速度を持つ）は ω の符号を保ったまま回り続ける 連続回転（上下の帯状軌道） になる。
演習1 (8) 発展

倒立位置の安定化制御

  • 真上（φ = 0）を基準にした座標では、少し傾くとさらに倒れる向きに重力トルクが働くため、重力項の符号が真下基準の - から + (g/l)*sin(φ) へ反転する。
  • PD制御（および重力補償）を加え、線形化後の特性方程式 λ^2 + kd*λ + (kp - g/l) = 0 において τ = -kd < 0（kd > 0）かつ Δ = kp - g/l > 0（kp > g/l）を満たせば、固有値の実部 σ が負になり倒立維持できる。

PART 2演習2「静電アクチュエータ」レポート (1)-(7) 記号まとめ

注意: 演習2（第13-14回）は期末試験では範囲外の可能性もあります（掲示等で確認）。ただしここで使う「1階変換 -> ニュートン法 -> ヤコビアン一般化 -> 相図と物理の対応」は他の問題でもそのまま使えます。
演習2 (1)-(2)

無次元式・固定点条件・ニュートン法

dz/dt = v, dv/dt = -β*v - z + α / (1 - z)^2 (物理範囲 0 <= z < 1, α >= 0, β > 0) 固定点条件: dz/dt = 0, dv/dt = 0 => v* = 0 かつ α = z* * (1 - z*)^2 ニュートン法: f(z) = α - z*(1 - z)^2, f'(z) = (1 - z)*(3*z - 1), z_{k+1} = z_k - f(z_k)/f'(z_k)
  • 停止する条件: f'(z) = 0 すなわち z = 1/3（曲線 z(1-z)^2 の山の頂上）や z = 1 では接線が水平になり分母 0 で更新が止まる。
演習2 (3)-(5)

一般記号のまま求めるヤコビアンと物理的意味

J(z*, 0) = [ [ 0 , 1 ], [ -1 + 2*α/(1 - z*)^3 , -β ] ] 固定点条件 α = z*(1 - z*)^2 を代入して α を消去すると: J(z*, 0) = [ [ 0 , 1 ], [ (3*z* - 1)/(1 - z*) , -β ] ] よって τ = -β, Δ = (1 - 3*z*) / (1 - z*)
  • 数値なしでも一発で安定性が読める: 0 < z* < 1/3 の固定点では分子 1 - 3*z* > 0 より Δ > 0、かつ τ = -β < 0（実部 σ < 0）なので必ず 漸近安定（黒丸・時計回り）（τ^2 - 4Δ < 0 なら渦状点、> 0 なら結節点）。
    一方、1/3 < z* < 1 の固定点では Δ < 0 なので必ず 鞍点（不安定・白丸） になる。
  • 物理的理由: ばねの引き戻す力 z の増え方と静電力 α/(1-z)^2 の増え方を比べると、山の左側 (z* < 1/3) ではばねの増加率が勝って戻り、山の右側 (z* > 1/3) では静電力の増加率が勝って電極へ引き込まれる（プルイン）。
演習2 (6)-(7)

サドルノード分岐と電圧フィードバック制御

  • 分岐条件（一般記号）: g(z) = z(1-z)^2 の極大点 g'(z) = (1-z)(1-3z) = 0 は z = 1/3、極大値は α_crit = 4/27。α = α_crit の点では Δ = 0（固有値 0, -β）となり 線形化だけでは判定不可（半安定）。これを超えると固定点が消滅する。
  • 非負制約の理由: 電圧制御入力 α は V^2 に比例し常に非負（静電力は引力のみで斥力は出せない）のため、α(z, v) = max(0, α_ff - Kp*(z - z_ref) - Kd*v) と 0 でクリップする。

PART 3 (ここが差がつく)演習・発展問題 5つの攻略型（初見問題への応用レシピ）

発展型 1

パラメータによる挙動の場合分け・分岐（バネダンパ・減衰振り子・分岐）

線形バネダンパ系: m*y'' + c*y' + k*y = 0 (m, k > 0, c >= 0) J = [ [ 0 , 1 ], [ -k/m , -c/m ] ] => τ = -c/m, Δ = k/m, τ^2 - 4*Δ = (c^2 - 4*m*k) / m^2
条件（記号）固有値 λ = σ ± iω分類と相図減衰の種類
c = 0±i*sqrt(k/m)（純虚数 σ=0）中心点（中立安定・閉軌道）減衰なし
0 < c < 2*sqrt(m*k)σ < 0, ω != 0（複素共役）安定渦状点（黒丸・時計回り渦）不足減衰
c = 2*sqrt(m*k)λ = -sqrt(k/m)（負の実重解）安定退化ノード（黒丸・最速収束）臨界減衰
c > 2*sqrt(m*k)異なる2つの負の実数 λ2 < λ1 < 0安定ノード（黒丸・遅い軸へ接する）過減衰
  • 減衰付き単振り子 θ'' + b*θ' + (g/l)*sin(θ) = 0: J = [[0, 1], [-(g/l)cos(θ*), -b]]。真下 (0,0) は b^2 - 4*g/l の符号で上記と同じく渦状・臨界・ノードに分かれ、真上 (π,0) は Δ = -g/l < 0 のため b によらず常に 鞍点。
  • 一般の1変数分岐レシピ: 固定点条件をパラメータ μ = g(x) と書けたら、g'(x*) = 0 となる極値が固定点の個数が切り替わる分岐点（そこでは Δ = 0 となり線形化だけでは判定不可）。
発展型 2

最速収束ゲインの決め方と限界（なぜ臨界減衰が最速か）

倒立PD制御の固有値: λ = ( -kd ± sqrt(kd^2 - P) ) / 2 [ ただし P = 4*(kp - g/l) > 0 を固定 ] 収束の速さを決める指標: max( Re(λ1), Re(λ2) ) (この値が最も負に大きいほど速く 0 へ近づく)
図1: kd < sqrt(P) では速くなるが、kd > sqrt(P) を超えると遅い方の実固有値が 0 に近づき逆に収束が遅くなる
  • 記号での結論: kp を固定したときの最速収束条件は常に重解（臨界減衰）kd = 2*sqrt(kp - g/l)（τ^2 = 4*Δ）。
  • なぜゲインを無限に大きくできないか: 実機ではトルク飽和・センサノイズ増幅があり、数値計算（離散時間）では 1ステップの変化が過大になって 数値発散 するため。
発展型 3

実固有値（安定ノード・不安定ノード・退化ケース）の相図手描き

図2: 一般解 x(t) = c1*exp(λ1*t)*v1 + c2*exp(λ2*t)*v2 から描く相図の鉄則
  • 安定ノード (λ2 < λ1 < 0): exp(λ2*t) が先に 0 へ消えるため、十分時間が経つと軌道は 収束が遅い方向（|λ| が小さい固有ベクトル v1）に接しながら原点へ吸い込まれる。
  • 不安定ノード (0 < λ1 < λ2): 逆に遠方では成長が速い v2 方向へ伸びていく（原点付近は v1 に沿って出る）。
  • 零固有値を含むとき (λ1 < 0, λ2 = 0): v2 上は一切時間変化せず直線全体が固定点となり、外れた点は v1 と平行にそこへ吸い込まれる。
発展型 4

安定性の厳密定義と2つの反例（引っかけ問題対策）

漸近安定 <=> 「リアプノフ安定（近くに留まる）」 かつ 「吸引的（t -> inf で近づく）」
  • 反例A [リアプノフ安定だが吸引的でない]: 減衰なし単振り子の最下点 θ* = 0（中心点・中立安定）。近くを回り続けるだけで原点には収束しない。
  • 反例B [吸引的だがリアプノフ安定でない]: 円周上の系 dθ/dt = 1 - cos(θ) の θ* = 0。すべての軌道は t -> inf で 0 へ吸い込まれるが、0 のすぐ手前（負側）から出発した点は円周をほぼ1周大きく離れてから戻るため、リアプノフ安定（＝漸近安定）ではない。
発展型 5

初見の非線形系を目標位置へ安定化する制御設計 3ステップ

設計公式: u(x, v) = u_ff(x_ref) - Kp * (x - x_ref) - Kd * v
  • Step 1（つり合い補償 u_ff）: 目標 (x_ref, 0) が固定点になるように重力・ばね力・静電力を打ち消す定常項を入れる（例: 倒立振り子の mgl*sin(θ)、静電アクチュエータの α_ff = z_ref*(1 - z_ref)^2）。
  • Step 2（誤差PDフィードバック）: 目標まわりで線形化し、τ < 0, Δ > 0（最速なら τ^2 = 4*Δ）を満たすように Kp, Kd を決める。
  • Step 3（物理制約と限界の明記）: アクチュエータの上下限・非負制約（例: 静電力は α >= 0 で max(0, ...) クリップ）と、「あくまで目標近傍の局所維持であり、遠い初期値からの振り上げ等は別設計が要る」ことを考察に書く。
