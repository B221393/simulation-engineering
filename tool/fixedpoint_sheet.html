固定点の安定性・分類・答案の決まり文句 暗記シート

シミュレーション工学 演習1・演習2 共通 // 「数値を見た瞬間にそのまま日本語で書ける」ための1枚まとめ
Step 1: まず Δ = det J を見る
Δ < 0 なら迷わず即「鞍点（不安定・白丸）」．
Δ = 0（固有値0を含む）なら即「線形化だけでは判定不可」．
Step 2: Δ > 0 なら τ = tr J を見る
固有値の実部の符号と一致：
τ < 0 -> 安定（黒丸）
τ > 0 -> 不安定（白丸） / τ = 0 -> 中心点
Step 3: 虚部の有無 (τ² - 4Δ)
τ² - 4Δ < 0（虚部あり）-> 渦状点（回る）
τ² - 4Δ > 0（実数のみ）-> 結節点（直進）
固定点の分類 固有値の特徴 τ, Δ の条件 相図の丸 試験でそのまま書ける決まり文句
安定渦状点
（安定焦点）		 実部 < 0，虚部あり τ < 0, Δ > 0
τ² - 4Δ < 0		 黒丸 「実部が負で虚部が存在するので，固定点は安定な渦状点である（相図では黒丸）．」
不安定渦状点
（不安定焦点）		 実部 > 0，虚部あり τ > 0, Δ > 0
τ² - 4Δ < 0		 白丸 「実部が正で虚部が存在するので，固定点は不安定な渦状点である（相図では白丸）．」
中心点
（中立安定）		 実部 = 0（純虚数） τ = 0, Δ > 0 白丸等
（閉軌道）		 「固有値の実部が 0 の純虚数なので，線形化系では中心点（中立安定）である．」
安定結節点 2つとも負の実数 τ < 0, Δ > 0
τ² - 4Δ > 0		 黒丸 「2つの固有値がともに負の実数（虚部なし）なので，固定点は安定な結節点である（相図では黒丸）．」
不安定結節点 2つとも正の実数 τ > 0, Δ > 0
τ² - 4Δ > 0		 白丸 「2つの固有値がともに正の実数なので，固定点は不安定な結節点である（相図では白丸）．」
鞍点
（サドル）		 正と負の実数（異符号） Δ < 0 白丸 「正と負の実固有値を持つ（Δ < 0）ので，固定点は不安定な鞍点である（相図では白丸）．」
非双曲型
（分岐点等）		 固有値 0 を含む Δ = 0 非線形で
判定		 「固有値に 0（実部 0）を含むため，線形化だけでは安定性を判定できない．」
相図の向き・固有ベクトルの覚え方（3つの即決ルール）
1. 渦巻きの回転向き：位置が横軸 z・速度が縦軸 v (= dz/dt) なら，上半分 (v > 0) は右向き・下半分 (v < 0) は左向きに進むため，必ず 時計回り．
2. 鞍点の固有ベクトル：J の1行目が [0, 1] のとき，(J - λI)w = 0 の1行目は -λ w1 + w2 = 0 なので w = (1, λ)^T（傾きがそのまま固有値 λ）．
3. 固有ベクトルの矢印：λ > 0 の直線は白丸から離れる（外向き），λ < 0 の直線は白丸へ向かう（内向き）．
