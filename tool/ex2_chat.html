[1] 無次元運動方程式と1階変換

変位 z = x/d（物理範囲 0 ≤ z < 1、z=1 で接触）、 α = ε0AV2/(2kd3) ≥ 0（電圧の強さ）、 β = c/√(km)（減衰の強さ）。

z'' = −βz' − z + α(1 − z)2
状態変数 z, v = z' を置くと（1階連立微分方程式）:
z' = v
v' = −βv − z + α(1 − z)2
固定点条件（z' = 0 かつ v' = 0）:

z' = 0 より v = 0。これを v' = 0 に代入すると 0 = −z + α/(1−z)2 となり、 両辺に (1−z)2 ≠ 0 を掛けて α = z(1−z)2。

[2] ニュートン法（固定点の数値探索）

f(z) = α − z(1 − z)2 = −z3 + 2z2 − z + α
f'(z) = −(1 − z)2 + 2z(1 − z) = (1 − z)(3z − 1) = −3z2 + 4z − 1
zk+1 = zk − f(zk)f'(zk)
  • 曲線 y = z(1−z)2 の山の頂上は z = 1/3（極大値 4/27）。
  • 2つの根（α = 36/343）は z* = 1/7 と z* = 4/7（3つ目の根 9/7 > 1 は物理範囲外）。
  • 失敗する初期値: z0 = 1/3, 1 では f'(z0) = 0 でゼロ除算停止。z0 ≈ 1/3 付近は接線が水平に近く大きく飛ぶ。z0 > 1 は範囲外の根 9/7 へ収束。

[3] 線形化・ヤコビアン・安定性判別（最頻出）

J(z, v) = ∂z'/∂z∂z'/∂v ∂v'/∂z∂v'/∂v = 01 −1 + 2α(1−z)3−β
固定点 α = z*(1−z*)2 上では左下の成分が −1 + 2z*/(1−z*) = (3z*−1)/(1−z*) と暗算レベルまで簡単化できる（検算に超便利）。
特性方程式: λ2 − τλ + Δ = 0
トレース τ = tr J = −β、行列式 Δ = det J = 1 − 2α/(1−z*)3
固有値: λ = (τ ± √(τ2 − 4Δ)) / 2
条件 (τ, Δ) 固有値 分類と丸 演習での例 (β=1)
Δ < 0 正と負の実数 鞍点（不安定・白丸） z* = 4/7 (τ=-1, Δ=-5/3)
τ < 0, Δ > 0, τ2−4Δ < 0 実部負の複素数 安定渦状点（漸近安定・黒丸） z* = 1/7 (τ=-1, Δ=2/3)
τ < 0, Δ > 0, τ2−4Δ > 0 2つとも負の実数 安定結節点（漸近安定・黒丸） z* = 1/7, β = 2 のとき
Δ = 0 または Re(λ) = 0 固有値0を含む 非双曲型（線形化のみでは判定不可） 分岐点 α = 4/27, z* = 1/3
手描き相図の鉄則:
1) 安定なら黒丸、不安定なら白丸。2) 横軸 z・縦軸 v=z' なので、上半分 (v>0) は右向き、下半分 (v<0) は左向き（よって渦巻は必ず時計回り）。3) 鞍点の固有ベクトルは1行目 −λw1 + w2 = 0 より w = (1, λ)T（傾きがそのまま λ）。λ>0 は外向き、λ<0 は内向き矢印。

[4] 4次ルンゲクッタ法 (RK4) とバグ注意

kz1 = func_dz(t, z, v, ...) ; kv1 = func_dv(t, z, v, ...)
kz2 = func_dz(t+dt/2, z+dt*kz1/2, v+dt*kv1/2, ...)
kv2 = func_dv(t+dt/2, z+dt*kz1/2, v+dt*kv1/2, ...) <-- func_dz 誤記注意!
kz3 = func_dz(t+dt/2, z+dt*kz2/2, v+dt*kv2/2, ...) ; kv3 = func_dv(...)
kz4 = func_dz(t+dt, z+dt*kz3, v+dt*kv3, ...) ; kv4 = func_dv(...)
z_next = z + dt*(kz1 + 2*kz2 + 2*kz3 + kz4)/6
v_next = v + dt*(kv1 + 2*kv2 + 2*kv3 + kv4)/6

連立系では k1, k2, k3, k4 ごとに z と v を同時に更新した中間点を渡すこと。 正しいRK4では (0.6, 0) は t = 2.39 で接触、(0, 0.5) は収束、(0, 0.8) は t = 2.91 で接触する。

[5] 物理的解釈・サドルノード分岐・制御

  • なぜ 1/7 は安定で 4/7 は不安定か: ばね力 z は直線的に増えるが、静電力 α/(1−z)2 は z → 1 で急増する。z* < 1/3 では「ずれてもばね（または静電力の復元側）が勝つ」が、z* > 1/3 では少し近づくだけで静電力の増加がばねを上回り一気に引き込まれる（プルイン）。
  • 分岐条件 (g(z) = z(1−z)2): g'(z) = (1−z)(1−3z) = 0 より z = 1/3 で極大値 4/27。 0 < α < 4/27 で2個、α = 4/27 で1個（z*=1/3、固有値 0, -1）、α > 4/27 で0個（全域で接触）。
  • 制御（発展）: 目標 zref > 1/3 に止めるには定常補償 αff = zref(1−zref)2 に PD制御を加え、α = max(0, αff − Kp(z−zref) − Kdv) と非負制約を課す。
