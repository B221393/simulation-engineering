第1部：暗記必須の公式・アルゴリズム整理

[1] 無次元運動方程式と1階変換

変位 z = x/d（物理範囲 0 ≤ z < 1）、α = ε0AV2/(2kd3) ≥ 0、β = c/√(km)。
z'' = −βz' − z + α(1−z)2
z' = v,  v' = −βv − z + α(1−z)2
固定点 (z'=0, v'=0): 第1式より v = 0。第2式に代入し両辺に (1−z)2 を掛けて α = z(1−z)2。

[2] ニュートン法（固定点の探索）

f(z) = α − z(1−z)2
f'(z) = −(1−z)2 + 2z(1−z) = (1−z)(3z−1)
zk+1 = zk − f(zk)f'(zk)
  • α = 36/343 の根: z* = 1/7 と z* = 4/7（第3根 9/7 > 1 は範囲外）。
  • 失敗初期値: z0 = 1/3, 1 は f'(z0)=0 でゼロ除算停止。z0 > 1 は範囲外の根へ収束。

[3] 線形化・ヤコビアン・安定性判別（最頻出）

J = ∂z'/∂z∂z'/∂v∂v'/∂z∂v'/∂v = 01−1 + 2α(1−z)3−β
固定点上（α = z*(1−z*)2）では左下成分は (3z*−1)/(1−z*) と簡約できる。
特性方程式: λ2 − τλ + Δ = 0（τ = tr J, Δ = det J）、固有値 λ = (τ ± √(τ2−4Δ))/2。
条件固有値分類・丸例 (α=36/343)
Δ < 0異符号の実数鞍点（不安定・白丸）z*=4/7, β=1
τ<0, Δ>0, τ2−4Δ<0実部負の複素数安定渦状点（黒丸）z*=1/7, β=1
τ<0, Δ>0, τ2−4Δ>0負の実数2個安定結節点（黒丸）z*=1/7, β=2
Δ = 00を含む非双曲型（判定不可）z*=1/3, α=4/27
図1: (1/7, 0) 近傍の線形相図（安定渦状点・黒丸・時計回り）
図2: (4/7, 0) 近傍の線形相図（鞍点・白丸・傾き +0.88 外向き / -1.88 内向き）

[4] 4次ルンゲクッタ法 (RK4) 実装と分岐・物理の要点

kz1 = func_dz(t[n], z[n], v[n], alpha, beta) ; kv1 = func_dv(t[n], z[n], v[n], alpha, beta)
kz2 = func_dz(t[n]+dt/2, z[n]+dt*kz1/2, v[n]+dt*kv1/2, alpha, beta)
kv2 = func_dv(t[n]+dt/2, z[n]+dt*kz1/2, v[n]+dt*kv1/2, alpha, beta)  # <-- func_dz 誤記注意!
# kz3, kv3 (k2の中間点), kz4, kv4 (k3の終点) も同様に求め、(k1+2*k2+2*k3+k4)/6 で同時更新
  • 非線形相図と物理: 鞍点 (4/7, 0) の安定多様体が「収束領域」と「引き込み領域」の境界（セパラトリクス）。z* = 1/7 はばねの増加率が勝つため安定、z* = 4/7 は静電力の増加率が勝つため不安定。
  • サドルノード分岐: g(z)=z(1−z)2 は z=1/3 で極大値 4/27。0 < α < 4/27 で固定点2個、α = 4/27 で1個（固有値 0, −1・不安定/半安定）、α > 4/27 で0個（全領域で接触）。
  • 制御（発展）: α(z,v) = max(0, zref(1−zref)2 − Kp(z−zref) − Kdv) とすることで zref > 1/3 でも安定保持できる。
第2部：手計算・記述 予想問題と完全解答（全7問）

問1：1階微分方程式と固定点条件の導出

必出・基礎
z'' = −βz' − z + α/(1−z)2 を z, v = z' の1階系に直し、固定点で v=0, α=z(1−z)2 を導け。
[解答] z' = v, v' = −βv − z + α/(1−z)2。固定点 (z'=0, v'=0) では第1式より v=0。第2式へ代入して 0 = −z + α/(1−z)2。0 ≤ z < 1 より両辺に (1−z)2 を掛けて α = z(1−z)2。

問2：ニュートン法の1ステップ手計算と失敗条件

手計算
α = 36/343, f(z) = α − z(1−z)2 のとき、(a) f'(z) = 0 となる点、(b) z0 = 1/2 からの1回目の更新値 z1 を分数で求めよ。
[解答] (a) f'(z) = −(1−z)2 + 2z(1−z) = (1−z)(3z−1) = 0 より z = 1/3, 1（更新式分母が0で停止）。
(b) f(1/2) = 36/343 − 1/8 = −55/2744, f'(1/2) = 1/4。よって z1 = 1/2 − (−55/2744)/(1/4) = 1/2 + 55/686 = 199/343 (≈ 0.5802)。

問3：ヤコビアン・固有値・固有ベクトル・相図

最頻出・大問候補
α = 36/343, β = 1 における z* = 1/7 と z* = 4/7 の J, τ, Δ, 固有値, 鞍点の固有ベクトルを分数で求め、相図を分類せよ。
[解答] z*=1/7: J21 = −1 + (72/343)/(216/343) = −2/3。よって J = [[0, 1], [-2/3, -1]], τ = −1, Δ = 2/3, τ2−4Δ = −5/3 < 0, λ = (−1 ± i√(5/3))/2 -> 安定渦状点（黒丸・時計回り）。
z*=4/7: J21 = −1 + (72/343)/(27/343) = 5/3。よって J = [[0, 1], [5/3, -1]], τ = −1, Δ = −5/3 < 0, λ± = (−3 ± √69)/6, 固有ベクトル w± = (1, λ±)T -> 鞍点（白丸）。

問4：減衰係数 β を変えた場合の固定点分類

応用手計算
問3で β = 2 に増やしたとき、z* = 1/7 と z* = 4/7 の分類はどう変わるか。
[解答] z*=1/7 では τ = −2, Δ = 2/3, τ2−4Δ = 4 − 8/3 = 4/3 > 0, 固有値 λ = −1 ± 1/√3 < 0（負の実数2個）となり、安定結節点へ変わる。z*=4/7 は Δ = −5/3 < 0 のままなので依然として鞍点。

問5：相図の境界と安定性が異なる物理的理由

記述
(a) (0, 0.5) は収束し (0, 0.8) は接触する理由、(b) 1/7 が安定で 4/7 が不安定な物理的理由を説明せよ。
[解答] (a) 非線形相図では鞍点 (4/7, 0) に入る安定多様体が収束領域と引き込み領域を分ける境界（セパラトリクス）となり、(0, 0.8) は初速が大きく境界を越えるため接触する。
(b) ばねの復元力 z は線形だが静電力 α/(1−z)2 は z → 1 で急増する。1/7 ではばねの増加率が大きく押し戻される（安定）が、4/7 では静電力の増加率が上回り電極側へ引き込まれる（不安定）。

問6：サドルノード分岐と分岐点での判定

応用
0 ≤ z < 1 の固定点数が変わる α (>0) の条件と、α = 4/27 で線形化だけでは安定性判定できない理由を述べよ。
[解答] g'(z) = (1−z)(1−3z) = 0 より z=1/3 で極大値 4/27。よって 0<α<4/27 で2個、α=4/27 で1個 (z*=1/3)、α>4/27 で0個。α=4/27 では固有値が λ = 0, −1 となり実部0を含むため線形化だけで判定できない（非線形軌道では z<1/3 から近づき z>1/3 から逃げるため不安定／半安定）。

問7：プログラムのバグ修正と制御制約

コード
(a) RK4の kv2 に誤って func_dz を書いた場合に何が起きるか。(b) 電圧制御則で α ≥ 0 とする理由は何か。
[解答] (a) dv/dt ではなく dz/dt を混ぜるため運動が誤り、接触時刻がずれたり本来収束する (0, 0.5) が接触する誤結果になる。
(b) α ∝ V2 は電圧の2乗に比例するため負にできない（静電力は常に引力）。
