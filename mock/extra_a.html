追加問題　解答と採点の目安

第10問〜第12問　／　60点満点
この追加問題の位置づけ
本試験（第1問〜第9問）は、オイラー法・ルンゲ・クッタ法・高階ODE・モデル化・振り子・線形系の安定性・PD制御・ニュートン法を扱った。一方、第5回〜第6回の中心である「1次元系の相図と固定点の分類」「刻み幅と精度の関係」「2次系（バネダンパ系）のステップ応答」は出題していなかった。追加問題はこの3つを補うものである。本試験と合わせて、第1回〜第12回の範囲をひととおり覆う。
第10問　1次元系の相図と固定点（20点）

(1) 固定点

4点

f(x) = x2(1 − x) = 0 を解く。x2 = 0 または 1 − x = 0 であるから

x = 0,　x = 1

x = 0 は重解（2重根）である。このことが次の(2)で効いてくる。

(2) 線形化と符号による判定

8点

f′(x) = 2x − 3x2 である。

x = 1 について

f′(1) = 2 − 3 = −1 < 0

したがって x = 1 は安定な固定点（アトラクター）である。

x = 0 について

f′(0) = 0

1次近似の係数が 0 になるため、線形化では判定できない（f′(x*) = 0 のときは高次の項が支配する）。そこで f の符号を調べる。

x < 0：x2 > 0、1 − x > 0 より f > 0（右向き、0 に近づく）
0 < x < 1：x2 > 0、1 − x > 0 より f > 0（右向き、0 から離れる）

左側からは引き寄せ、右側からは押し返すので、x = 0 は半安定な固定点である。

配点の内訳：f′ の計算 2点、x = 1 の判定 2点、f′(0) = 0 で判定不能と述べたこと 2点、符号による半安定の結論 2点。「不安定」とだけ書いた答案は、左側からの吸引を見落としているので 4点。

(3) 相図

4点

f(x) = x2 − x3 の概形は、x = 0 と x = 1 で 0 になり、f′(x) = 2x − 3x2 = 0 より x = 2/3 で極大値 4/27 ≈ 0.148 をとる。x < 0 では正、x > 1 では負である。

図：f(x) = x²(1 − x) のグラフと、x 軸上の解の流れ（下段の矢印）

矢印は、x < 0 では右向き（0 へ）、0 < x < 1 では右向き（1 へ）、x > 1 では左向き（1 へ）となる。

配点の内訳：グラフの概形（0 と 1 で 0 を通る）2点、矢印の向き 2点。極大値まで書く必要はないが、x > 1 で負になることを示していない答案は 1点減。

(4) 初期値ごとの長時間挙動

4点
初期値t → ∞ の行き先理由
x0 = −0.5x → 00 の左側では f > 0 で右へ流れ、0 に吸い込まれる。
x0 = 0.5x → 10 と 1 の間では f > 0 で右へ流れ、1 に吸い込まれる。
x0 = 2x → 11 の右側では f < 0 で左へ流れ、1 に吸い込まれる。

配点の内訳：3つとも正しく答えて4点。1つ誤りで2点。0 と 1 の間の初期値が 0 に戻るとした答案は、半安定の理解が逆になっているので0点。

第11問　刻み幅と精度（20点）

(1) 次数

4点
手法1ステップあたりの誤差一定時間後の積算誤差
前進オイラー法O(Δt2)O(Δt)（1次精度）
ホイン法（2次RK）O(Δt3)O(Δt2)（2次精度）
RK4O(Δt5)O(Δt4)（4次精度）

積算誤差の次数は、1ステップの誤差をステップ数 1/Δt 倍したものだから、1つ低い次数になる。

(2) Δt を 1/2 にしたときの誤差の比

8点
手法0.100 → 0.050 の比推定した次数理論値 2n
前進オイラー法1.553×10−1 ÷ 7.379×10−2 = 2.101次2
ホイン法8.973×10−2 ÷ 1.458×10−2 = 6.152次4
RK43.489×10−3 ÷ 1.483×10−4 = 23.54次16

比は 2n の形で増えるので、両対数グラフの傾き、または log2(比) から次数 n を読み取れる。log2 2.10 ≈ 1.1、log2 6.15 ≈ 2.6、log2 23.5 ≈ 4.6 となる。

実測の比が理論値（2、4、16）より大きいのは、Δt がまだ十分小さくなく、打ち切り誤差の高次の項が効いているためである。表の下の行（0.025 → 0.0125）では 2.05、4.38、17.6 となり、理論値に近づいていく。この「Δt を小さくすると比が理論値に収束する」ことが、次数の確認になっている。

配点の内訳：3つの比の計算 3点、次数の推定 3点、理論値とのずれの説明 2点。比を計算せずに「オイラーは1次」と暗記で書いただけの答案は 3点。

(3) RK4 が実用上よく使われる理由

4点

1ステップあたりに f を評価する回数は、前進オイラー法が1回、ホイン法が2回、RK4 が4回である。RK4 は1ステップのコストが4倍かかるが、4次精度なので刻み幅を大きく取れる。

表から、RK4 は Δt = 0.05 で誤差 1.5×10−4 を得ている。同じ誤差を前進オイラー法で得るには、誤差が O(Δt) で 7.4×10−2（Δt = 0.05）だから、Δt を約 1/500 の 1×10−4 まで小さくする必要がある。このとき t = 0.2 までのステップ数は約 2000 で、f の評価は 2000 回。RK4 は 4ステップ × 4回 = 16 回で済む。したがって、精度あたりの計算コストは RK4 が圧倒的に小さい。

配点の内訳：1ステップの評価回数（1、2、4）2点、精度あたりのコスト比較 2点。「RK4 は精度が良い」だけでは理由になっていないので 1点。

(4) 安定条件の確認

4点

k = −9、Δt = 0.1 のとき、前進オイラー法の増幅率は

1 + kΔt = 1 − 0.9 = 0.1

|0.1| < 1 なので安定である。安定条件は |1 + kΔt| ≤ 1 より Δt ≤ 2/|k| = 2/9 ≈ 0.222 であり、Δt = 0.1 はこれを満たす。

ただし、安定であることと精度が良いことは別である。表のとおり、この刻み幅でのオイラー法の誤差は 1.55×10−1 で、真値 0.165 に対してほぼ 100 % の誤差がある。

配点の内訳：増幅率の値 2点、Δt ≤ 2/9 の導出 1点、安定と精度は別という指摘 1点。

第12問　2次系のステップ応答（20点）

(1) 1階連立への変形

4点

v = dx/dt とおくと、d2x/dt2 = dv/dt であるから

dxdt = v　,　 dvdt = 1 − 2v − x

ベクトル表記では d/dt [x, v]T = [v, 1 − x − 2v]T となる。

配点の内訳：状態変数の定義 2点、2式の完成 2点。符号（−2v − x）を落とした答案は 2点。

(2) 固定点

3点

dx/dt = 0 より v = 0。dv/dt = 0 より 1 − x = 0、すなわち x = 1。

(x, v) = (1, 0)

これはステップ応答の収束先（最終値 1）に対応する。

(3) ヤコビアンと固有値

f1 = v、f2 = 1 − x − 2v とおくと

この系は線形なので、ヤコビアンは固定点によらず一定である。特性方程式は

det(J − λE) = λ(λ + 2) + 1 = λ2 + 2λ + 1 = (λ + 1)2 = 0
λ = −1（重解）

トレース τ = −2、行列式 Δ = 1 であるから、τ < 0、Δ > 0、τ2 − 4Δ = 0 より漸近安定な結節点（臨界減衰）である。

配点の内訳：ヤコビアン 3点、特性方程式と固有値 2点、τ-Δ による判定と減衰の種類 1点。固有値を −1 と −1 と書けても、減衰の種類を答えていない答案は 5点。

(4) ステップ応答の概形

4点

臨界減衰のときの解は x(t) = 1 − (1 + t)e−t である。確認すると、x(0) = 1 − 1 = 0、dx/dt = t e−t より t = 0 で傾き 0、t → ∞ で x → 1。dx/dt = t e−t ≥ 0（t ≥ 0）なので単調増加で、オーバーシュートはない。

図：臨界減衰のステップ応答。初期傾き 0、単調増加、最終値 1、オーバーシュートなし

配点の内訳：最終値 1 と初期傾き 0 の明記 2点、単調増加（オーバーシュートなし）1点、グラフの概形 1点。

(5) 減衰係数を変えたとき

3点
条件減衰の種類応答の変化
c > 2（ζ > 1）過減衰振動せずにゆっくり収束する。速く収束させるには、臨界減衰より大きな c が必要になり、整定は遅くなる。
c = 2（ζ = 1）臨界減衰オーバーシュートせず、最も速く収束する。
c < 2（ζ < 1）不足減衰振動しながら収束する。オーバーシュートが生じ、c が小さいほど振動が長く続く。

配点の内訳：2つの場合の名前と挙動 2点、臨界減衰が最速であることの言及 1点。
