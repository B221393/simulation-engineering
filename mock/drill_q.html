1. 誤差回避大きい数＋小さい数は情報落ち（float32は有効桁約7桁）。近い数同士の引き算は桁落ち（解と係数の関係や有理化で和の形に変形する）。
2. 1階ODE更新前進オイラー: x[n]+dt*f ／ 陰解法(dx/dt=kx): x[n]/(1-k*dt) ／ ホイン法: k1=dt*f(t,x), k2=dt*f(t+dt, x+k1), x+(k1+k2)/2 ／ RK4: t+dt/2 に注意し (k1+2*k2+2*k3+k4)/6。
3. 2階・多変数ODEx'' = ... を dx/dt=v, dv/dt=... に分解。RK4は必ず全成分の k1 を求めてから全成分を k1/2 進めて k2 を計算し、最後に同時更新する。
4. 制御・外力系PD制御は u = kp*(0 - phi) - kd*omega を計算してから domega へ入れる。角加速度の分母（m や m*l**2）を落とさない。
5. ニュートン法・連立1D: x_new = x - fx / dfx ／ 2D: J @ delta = -f を np.linalg.solve(Jz, -fz) で解く（逆行列を直接作らない）。
