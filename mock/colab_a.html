第14問　Colab演習：RK4の実装バグと妥当性検証（第3回〜第8回）

10点

(1) RK4実装の2つのバグと修正（4点）

  • 誤り(a) 04〜05行目：k2x と k2v を計算するときに、すべての状態変数を同時に半ステップ（k1/2）進めた点で右辺を評価していない（04・05行目の第3引数 v[n] が k1v/2 だけ進んでいない）。
    修正コード： 
    04:     k2x = dt * func_dx(t[n] + dt/2, x[n] + k1x/2, v[n] + k1v/2, m, k_spring)
05:     k2v = dt * func_dv(t[n] + dt/2, x[n] + k1x/2, v[n] + k1v/2, m, k_spring)
  • 誤り(b) 13行目（非自律系での時刻引数）：右辺 f(t, x) が時刻 t を陽に含む（例：sin(t) − x3）にもかかわらず、k2（および k3）で時刻を t[n] のまま渡している。
    修正コード：k2 = dt * func(t[n] + dt/2, x[n] + k1/2)（同様に k3 は t[n] + dt/2、k4 は t[n] + dt を渡す）。

(2) シミュレーションの妥当性検証法（4点）

  • (a) 解析解が書けない非線形系（dx/dt = sin(t) − x3）： 時間刻み幅 Δt を半分・1/10と段階的に小さくして計算結果を比較し、値が十分収束して変わらなくなるか確認する（また、異なる手法：オイラー法とRK4の結果が Δt → 0 で一致するか、あるいは定常状態・平衡点の振る舞いが式の符号と整合するか確認する）。
  • (b) 減衰なし単振り子（演習1）： 力学的エネルギー保存則 E = (1/2) m (l ω)2 + m g l (1 − cosθ) が時間経過とともに一定に保たれているか確認する。さらに Δt を変えてエネルギー誤差 |E(t) − E(0)| を両対数グラフに描き、オイラー法なら傾き1（O(Δt)）、RK4なら傾き4（O(Δt4)）になることを確認すればプログラムにバグがない強い根拠になる。

(3) 前進オイラー法で単振動の相図が外側に広がる理由（2点）

単振動の微分方程式 dx/dt = v, dv/dt = -(k/m)x に前進オイラー法を適用すると、1ステップごとの更新行列の固有値の絶対値が √(1 + (k/m)Δt2) > 1 となり、全エネルギー（相図上の円の半径の2乗）がステップごとに単調増加し続けるため、軌道は閉じた円にならず外側に発散する渦巻きを描く。

Colab実装の頻出ミス

「2変数で x[n+1] を先に計算してその新しい値で v[n+1] を更新してしまう」のもよくあるミス（これは前進オイラー法ではなく半陰解法になる）。試験でも「全成分の k1 を求めてから全成分を半ステップ進めて k2 を計算する」ことを常に意識すること。

第15問　Colab演習：逆振り子の反り返りと外力固定（第5〜6回応用）

10点

(1) 1階連立化と反り返りの理由（4点）

(a) 1階の連立微分方程式：両辺を m l2 で割ると次式になる（分母が m l ではなく m l2 であることに注意）。

dθdt = ω ,　　 dωdt = l F − m g l cosθ − d ωm l2

(b) 固定点が存在しない理由：固定点では ω = 0, dω/dt = 0 より m g cosθ* = F、すなわち cosθ* = F / (mg) を満たす必要がある。しかし数値例では F = 15 > mg = 9.8 なので F / (mg) ≈ 1.53 > 1 となり、|cosθ*| ≤ 1 を満たす実数 θ* が存在しない。したがって噴射力トルクが常に重力トルクに勝ち、棒が一方向に回り続ける。

(2) 外力方向固定時の固定点と F → ∞ の極限（4点）

固定点条件 F cos(ψ + θ*) = m g cosθ* に加法定理 cos(ψ + θ*) = cosψ cosθ* − sinψ sinθ* を代入すると、

(F cosψ − m g) cosθ* = F sinψ sinθ*　⇒　 tanθ* = F cosψ − m gF sinψ

F → ∞ とすると mg / F → 0 より tanθ* → cosψ / sinψ = tan(π/2 − ψ)。つまり θ* は π/2 − ψ（たとえば ψ = 45° のときは 45° = π/4、外力の作用線が棒と一直線になり重力を無視して外力と平行に釣り合う角度）へ近づく。

(3) ψ → 0° の挙動と初期値が大きい場合の挙動（2点）

  • ψ → 0° のとき：分母 sinψ → 0 となり、F > mg なら θ* → π/2（真上）に近づくが、角度のずれに対して復元トルクを生む成分 F sin(ψ+θ*) の回復効果が真上付近で小さくなり、外乱に弱くなる（ψ = 0 で F > mg の場合は真上で釣り合うが不安定／復元余地が狭まる）。
  • 初期角度が大きいとき（θ(0) = 2.5 rad 等）：線形化で証明できる漸近安定性はあくまで固定点近傍の局所的な性質であるため、非線形な系では初期状態が吸引領域（安定領域）の外にあると、別の固定点へ流れたり回転し続けたりして元の固定点へ戻らない場合がある。

(2) 2つの線形系の解析と相図（3点）

(3) トレース τ と相空間の面積変化（2点）

線形系で相空間上の任意の領域の面積は時間とともに eτ t に比例して変化するため、τ < 0 なら面積は収縮し、τ = 0 なら面積は保存され、τ > 0 なら面積は拡大する。

第19問　講義後半（穴埋め解除）：LU分解とべき乗法・逆べき乗法（第12回）

10点

(1) LU分解の求解手順と有利な点（3点）

手順：A x = L U x = b において y = U x とおくと、次の2段階で解ける。

  1. 前進代入：下三角行列の連立方程式 L y = b を上から順に解いて y を求める。
  2. 後退代入：上三角行列の連立方程式 U x = y を下から順に解いて x を求める。

有利な理由：Gaussの消去法では A と b を同時に変形するため b が変わるたびに O(n3) の前進消去をやり直す必要がある。一方、LU分解は A = L U の分解を1回だけ行っておけば、新しい b に対して計算量の軽い O(n2) の前進代入・後退代入だけで高速に解ける。
