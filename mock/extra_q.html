第10問　1次元系の相図と固定点（20点）

第10問

20点

次の1次元の微分方程式を考える。

dxdt = f(x) = x2(1 − x)
  1. 固定点（平衡点）をすべて求めよ。（4点）
  2. 各固定点について、f′(x) による線形化で安定性を判定せよ。線形化で判定できない固定点については、その理由と、f の符号から判定した結果を書け。（8点）
  3. 横軸に x、縦軸に dx/dt をとったグラフを描き、x 軸上に解の流れの矢印を書き入れよ。（4点）
  4. 初期値 x0 = −0.5、0.5、2 のそれぞれについて、t → ∞ で x がどこに近づくかを答えよ。（4点）
解答欄
第11問　刻み幅と精度（20点）

第11問

20点

dx/dt = −9x、x(0) = 1 を t = 0.2 まで数値的に解いた。真値は e−1.8 = 0.165299 である。刻み幅 Δt を変えたときの、真値との誤差を次の表に示す。

Δt前進オイラー法ホイン法（2次RK）RK4
0.1001.553 × 10−18.973 × 10−23.489 × 10−3
0.0507.379 × 10−21.458 × 10−21.483 × 10−4
0.0253.516 × 10−22.998 × 10−37.669 × 10−6
0.01251.715 × 10−26.844 × 10−44.363 × 10−7
  1. 前進オイラー法、ホイン法、RK4 のそれぞれについて、1ステップあたりの誤差と、一定時間後の積算誤差の次数を書け。（4点）
  2. Δt を 1/2 にしたときの誤差の比を、3つの手法それぞれについて表から計算せよ（0.100 → 0.050 の行でよい）。その比から、各手法の次数を推定せよ。（8点）
  3. 同じ精度の結果を得るために必要な f の計算回数を比較して、RK4 が実用上よく使われる理由を説明せよ。（4点）
  4. この問題の刻み幅 Δt = 0.100 は、前進オイラー法の安定条件 Δt ≤ 2/9 を満たしているか。増幅率 1 + kΔt の値を用いて答えよ。（4点）
解答欄
第12問　2次系（バネダンパ系）のステップ応答（20点）

第12問

20点

質量 m = 1、減衰係数 c = 2、ばね定数 k = 1 のバネダンパ系に、t ≥ 0 で一定の入力 u(t) = 1 を与える。運動方程式は次式で、初期値は x(0) = 0、v(0) = 0 とする。

d2xdt2 + 2 dxdt + x = 1
  1. 状態変数を (x, v) = (x, dx/dt) とおき、1階の連立微分方程式にせよ。（4点）
  2. 固定点を求めよ。（3点）
  3. 固定点まわりのヤコビアン行列を求め、固有値を計算して安定性を判定せよ。減衰の種類（不足減衰・臨界減衰・過減衰）も答えよ。（6点）
  4. ステップ応答 x(t) の概形を描け。最終値、t = 0 での傾き、オーバーシュートの有無に触れること。（4点）
  5. 減衰係数 c を 2 より大きくした場合と小さくした場合で、応答がどう変わるかを述べよ。（3点）
