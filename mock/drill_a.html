TODO-03　丸め誤差と無限級数（float32 の頭打ち）

検証: float32 N=10^5 誤差 2.09e-4
[1] for k in range(1, N + 1):
        total += 1.0 / (k ** 2)       # 単精度検証時は total += np.float32(1.0 / (k ** 2))

TODO-06　後退（陰解法）オイラー法

検証(dt=0.25, T=1): 0.008963
[1] x[n + 1] = x[n] / (1.0 - k * dt)

導出：xn+1 = xn + k xn+1 Δt を移項して (1 - k Δt) xn+1 = xn。k < 0 のとき常に 0 < 1/(1 - k Δt) < 1 となるため、任意の Δt > 0 で絶対安定（発散しない）。

第4回（04_runge_intro.ipynb）：ホイン法・RK4・非自律系RK4

TODO-08　ホイン法（2次RK）

検証(dt=0.1, T=1): 0.001079
k1 = dt * func_dx(t[n], x[n], k)
k2 = dt * func_dx(t[n] + dt, x[n] + k1, k)
x[n + 1] = x[n] + 0.5 * (k1 + k2)

ポイント：始点の傾き k1 と、オイラー法で仮に進んだ終点 (tn+Δt, xn+k1) の傾き k2 を平均する。2次精度 O(Δt2)。

TODO-09　4次のルンゲ・クッタ法（RK4）

検証(dt=0.1, T=1): 0.000137
k1 = dt * func_dx(t[n], x[n], k)
k2 = dt * func_dx(t[n] + dt / 2, x[n] + k1 / 2, k)
k3 = dt * func_dx(t[n] + dt / 2, x[n] + k2 / 2, k)
k4 = dt * func_dx(t[n] + dt, x[n] + k3, k)
x[n + 1] = x[n] + (k1 + 2 * k2 + 2 * k3 + k4) / 6

誤差頭打ちの理由：倍精度（float64）の表現限界（約16桁、マシンイプシロン ≈ 2.2e-16）に達し、Δt を極端に小さくすると打ち切り誤差より丸め誤差の蓄積が支配的になるため。

TODO-10　非線形・非自律系 dx/dt = sin(t) - x3 のRK4
