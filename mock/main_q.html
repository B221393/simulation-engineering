第1問　数値計算の誤差

8点
  1. 次の4つの用語を、それぞれ1〜2文で説明せよ。さらに、それぞれが実際に現れる計算例を1つずつ挙げよ。
    ① 丸め誤差　② 打ち切り誤差　③ 情報落ち　④ 桁落ち
  2. 単精度（float32）と倍精度（float64）は、実数をそれぞれ約何桁の10進数で表現できるか。
  3. 数値計算の誤差を理解することが、シミュレーションを行う上でなぜ重要か。「無意味な計算をしない」という語を用いて説明せよ。

第2問　オイラー法

10点

1階の常微分方程式 dx/dt = f(t, x)、初期条件 x(t0) = x0 を考える。

  1. 微分の定義から出発して、前進オイラー法の更新式を導出せよ。
  2. テイラー展開を用いて、前進オイラー法が1次精度であることを説明せよ。1ステップあたりの誤差と、一定時間後の積算誤差の次数をそれぞれ明記すること。
  3. dx/dt = −9x、x(0) = 1、Δt = 0.25 とする。前進オイラー法で x1 と x2 を求めよ。また、この刻み幅で計算が発散する理由を、増幅率 1 + kΔt を用いて説明せよ。
  4. 後退オイラー法の更新式を書き、同じ条件で x1 を求めよ。前進オイラー法との安定性の違いを述べよ。

第3問　ルンゲ・クッタ法と刻み幅

  2. 4次のルンゲ・クッタ法（RK4）の更新式を、k1〜k4 を用いて書け。
  3. オイラー法、ホイン法、RK4 について、1ステップあたりの誤差と、一定時間後の積算誤差の次数をそれぞれ答えよ。
  4. 刻み幅 Δt を 1/10 にしたとき、一定時間後の誤差はそれぞれ何倍になるか。上の次数を用いて答えよ。

第4問　高階微分方程式の取扱い

5点

質量 m、減衰係数 c、ばね定数 k のバネダンパ系

m d2xdt2 + c dxdt + k x = 0
  1. 状態変数を定義し、1階の連立微分方程式に変形せよ。
  2. ベクトル表記 dx/dt = f(x) で書け。
  3. この系に RK4 を適用するとき、各成分の計算で注意すべき点を述べよ。

第6問　固定点と相図（単振り子）

8点

長さ l の単振り子の運動は、角度 θ と角速度 ω を用いて次式で表される。

dθdt = ω　,　dωdt = − gl sinθ
  1. 固定点をすべて求めよ。ただし θ ∈ (−π, π] とする。
  2. ヤコビアン行列を求め、各固定点での固有値を計算して、固定点の種類と安定性を判定せよ。
  3. 次の6つの初期値から始めた運動が、振り子のどのような動きに対応するかを説明せよ。
    (θ, ω) = (0, 0), (π/2, 0), (π, 0), (−π, 0), (−π, 1), (π, −1)
    θが周期変数（−π〜π）であることに触れること。

第8問　逆振り子のPD制御

6点

支点にトルク入力を加えた振り子の運動方程式を、倒立状態を φ = 0 とする座標で書くと次式になる。

d2φdt2 = gl sinφ + u　,　 u = −kpφ − kddφdt　 (kp > 0, kd > 0)
  1. φ = 0 のまわりで線形化し、状態方程式 d/dt [φ, ω]T = A [φ, ω]T の行列 A を求めよ。
  2. 固定点 φ = 0 が漸近安定となるための kp、kd の条件を、τ と Δ を用いて導け。
  3. l = 1 m、g = 9.8 m/s2、kd = 6 のとき、臨界減衰（重解）となる kp を求めよ。
