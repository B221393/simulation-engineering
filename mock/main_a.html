第1問　数値計算の誤差

8点

(1) 4つの誤差（4点）

  • 丸め誤差：数を有限の桁数で表現することによって生じる誤差。コンピュータは有限桁でしか計算できないため必ず発生する。
    例：0.1 は2進数では有限桁で表せない。Python で 0.1 + 0.2 を計算すると 0.30000000000000004 になる。
  • 打ち切り誤差：無限回または多数回の演算を、有限回で打ち切るときに生じる誤差。
    例：ex = 1 + x + x2/2! + x3/3! + … を N 項で打ち切る。項数を増やせば小さくできる。
  • 情報落ち：大きい値と小さい値を足し算したとき、小さい値の情報が失われる現象。丸め誤差の一種。
    例：1.0×1016 + 1.0 を倍精度で計算すると 1.0×1016 のまま。
  • 桁落ち：近い値同士を引き算したときに、有効数字が失われて相対誤差が拡大する現象。丸め誤差の一種。
    例：√(108+1) − 104 や 1.0000001 − 1.0。有効数字の桁落ちと同じ原理。

※「測定誤差」は数値計算に起因するものではないため、ここには含めない。

(2) 表現できる桁数（2点）

単精度（float32）：約7桁。倍精度（float64）：約16桁。

(3) 誤差を理解する意義（2点）

計算結果の精度を自分で判断でき、作ったシミュレータが正しいかを判断できる。また、必要とする精度に対して計算方法と刻み幅を決められるので、無意味な計算をしないで済む。たとえば丸め誤差が支配的になっている領域では、Δt をいくら小さくしても精度は向上しない。

採点の目安

用語の定義（各0.5点）と例（各0.5点）。「情報落ち＝大きい値＋小さい値」「桁落ち＝近い値の減算」を区別できているかを重視する。単精度7桁・倍精度16桁は数値が合っていればよい。

第2問　オイラー法

10点

(1) 更新式の導出（3点）

微分の定義より

dxdt = limΔt→0 x(t+Δt) − x(t)Δt

Δt が十分小さければ、極限を取る前の式で近似できる。

x(t+Δt) − x(t)Δt ≈ f(t, x) 　⟹　x(t+Δt) ≈ x(t) + f(t, x)Δt

時刻を tn = t0 + nΔt、そのときの値を xn とおけば

xn+1 = xn + Δt f(tn, xn)

(2) 1次精度である理由（3点）

真の解を tn まわりでテイラー展開する。

x(tn+Δt) = xn + ẋ(tn)Δt + 12!ẍ(tn)Δt2 + ⋯

ẋ = f を用いれば

x(tn+Δt) = xn + f(tn, xn)Δt + O(Δt2)

前進オイラー法の更新式は右辺の第2項までであり、Δt2 以降を打ち切っている。したがって1ステップあたりの誤差は O(Δt2)。一定時間 T を進めるには T/Δt ステップ必要なので、積算誤差は

TΔt · O(Δt2) = O(Δt)

となり、1次精度である。

(3) 数値計算と発散（2点）

f = −9x、Δt = 0.25 より

x1 = 1 + 0.25·(−9·1) = 1 − 2.25 = −1.25
x2 = −1.25 + 0.25·(−9·(−1.25)) = −1.25 + 2.8125 = 1.5625

この系の1ステップの増幅率は xn+1 = (1 + kΔt)xn より 1 + kΔt = 1 − 2.25 = −1.25。絶対値が1より大きいので、値は符号を変えながら振動し、振幅が拡大する。安定条件 |1 + kΔt| ≤ 1 を満たすには Δt ≤ 2/|k| = 0.222… であり、Δt = 0.25 はこれを超えている。

参考：真値は x(0.25) = e−2.25 ≈ 0.105。

(4) 後退オイラー法（2点）

xn+1 = xn + Δt f(tn+1, xn+1)

f = kx のとき、右辺にも xn+1 が含まれるので xn+1 について解くと

xn+1 = xn1 − kΔt = 11 + 9×0.25 = 13.25 ≈ 0.308

増幅率は 1/(1+9Δt) ≈ 0.308 で、k < 0 かつ Δt > 0 なら常に絶対値が1未満である。したがって後退オイラー法（陰解法）は刻み幅を大きくしても発散しにくい。前進オイラー法（陽解法）は条件付きでしか安定でない。

採点の目安

(1) 微分の定義から近似式を経て更新式に至る流れ（3点）。(2) テイラー展開の2次の項が残ることを指摘し、O(Δt2) と O(Δt) の両方を書けたか（3点）。(3) 数値と増幅率の絶対値の議論（2点）。(4) 陰解法の式と安定性の違い（2点）。

第3問　ルンゲ・クッタ法と刻み幅

8点

(1) ホイン法（2点）

k1 = Δt f(tn, xn)
k2 = Δt f(tn+Δt, xn+k1)
xn+1 = xn + 12(k1 + k2)

(2) 4次ルンゲ・クッタ法（2点）

k1 = Δt f(tn, xn)
k2 = Δt f(tn+Δt/2, xn+k1/2)
k3 = Δt f(tn+Δt/2, xn+k2/2)
k4 = Δt f(tn+Δt, xn+k3)
xn+1 = xn + 16(k1 + 2k2 + 2k3 + k4)

(3) 誤差の次数（2点）

解法1ステップあたりの誤差一定時間後の積算誤差

(4) 刻み幅を1/10にしたとき（2点）

積算誤差が Δtp に比例するとすれば、Δt を 1/10 にすると誤差は (1/10)p 倍になる。

オイラー法：1/10 倍　／　ホイン法：1/100 倍　／　RK4：1/10000 倍

両対数グラフの傾きがそれぞれ 1、2、4 になることに対応する。実際には丸め誤差が下限となり、ある刻み幅より小さくしても改善しなくなる。

採点の目安

係数（1/2、1/6、1/3、1/6）と k2〜k4 の引数の取り方が正確か。次数の表は1ステップと積算の区別ができているかを確認する。

第5問　モデル化

5点

(1) 目的に応じたモデル（3点）

目的モデル状態変数パラメータ
A：速度変化質点の自由落下
mẍ = −mg		x, ẋm, g
B：姿勢変化剛体の自由落下
mẍ = −mg, Iθ̈ = 0		x, θ, ẋ, θ̇m, I, g

Cは接触の有無で式が切り替わる条件分岐付き微分方程式になる。

(2) 複雑化の弊害と単純化の利点（2点）

  • 複雑化の弊害：計算コストが激増する／調整すべきパラメータが増える／誤差の原因が特定しにくくなる／物理的な意味が分かりにくくなる。
  • 単純なモデルの利点：物理的な意味が理解しやすい／高速にシミュレーションできる／制御の設計が容易になる。

モデル化とは現実を丸ごと再現することではなく、目的に応じて重要な要素を選び、重要でない要素を無視する判断である。複雑なモデルが良いモデルとは限らず、目的に対して必要十分な複雑さがあればよい。

採点の目安

各目的に対応するモデルと状態変数（各1点）。弊害2つ・利点2つ（各0.5点）。目的と無関係に複雑なモデルを挙げている場合は減点。

(3) 初期値と運動の対応（3点）

  • (0, 0)：最下点で静止。固定点そのもの。
  • (π/2, 0)：最下点から90°の位置で静かに放した運動。行って戻る振動（リブレーション）で、相図では原点を囲む閉軌道になる。エネルギーが一定なので同じ軌道を回り続ける。非線形系なので周期は振幅に依存する。
  • (π, 0) と (−π, 0)：同一の固定点（真上）。θ は周期変数なので π と −π は同じ位置を表す。厳密には静止し続けるが、サドルで不安定なので、わずかな外乱（数値計算の丸め誤差を含む）で落下する。
  • (−π, 1)：真上から角速度1で放した運動。ω > 0 のまま回り続ける回転（大車輪）。相図では上下の帯状の軌道になり、θ が 2π 進むごとに同じ状態に戻る周期解である。回転中も |ω| は変化し、最下点で最大、真上で最小になる。
  • (π, −1)：上の逆向き。ω < 0 のまま逆方向に回り続ける。

この2つの回転軌道と、(±π, 0) を通る軌道（セパラトリクス）が、振動と回転の境界になっている。

第9問　ニュートン法

4点

(1) 更新式の導出（2点）

f(x + δ) = 0 となる δ を求めたい。f を x のまわりでテイラー展開し、2次以上を無視する。

f(x + δ) ≈ f(x) + f′(x)δ = 0 　⟹　δ = −f(x)f′(x)
xk+1 = xk − f(xk)f′(xk)

|δ| が十分小さくなるまで繰り返す。図形的には、点 (xk, f(xk)) における接線と x 軸の交点を次の近似解とする操作に対応する。

(2) 3√13 の計算（2点）

f(x) = x3 − 13、f′(x) = 3x2。

x0 = 2
x1 = 2 − 23 − 133·22 = 2 − −512 = 2.416666…
x2 = 2.416666… − 2.416666…3 − 133×(2.416666…)2 = 2.416666… − 1.1140…17.5208… ≈ 2.35308…

真値は 131/3 ≈ 2.351335。2回の反復で小数第2位まで一致しており、収束が速いことが分かる。

発展

(a) 連立方程式への拡張：f(x) = 0（f はベクトル関数）に対して、ヤコビアン J(xk) を用いて

J(xk)δ = −f(xk) 　⟹　xk+1 = xk + δ

各反復で線形連立方程式を解く必要がある。δ は逆行列を計算せず、消去法などで解く方がよい。

(b) 収束しない理由：f(x) = x3 − 2x + 2、x0 = 0 とすると f(0) = 2、f′(0) = −2 より x1 = 1。次に f(1) = 1、f′(1) = 1 より x2 = 0 に戻る。0 と 1 の間を往復する2周期に入り、収束しない。初期値の選び方によってはニュートン法が失敗する例である。

採点の目安

テイラー展開から δ = −f/f′ を導く流れ（2点）、x1 と x2 の数値（2点）。有効数字3桁程度でよい。

解答のポイントと復習の優先順位

参考

本番で問われる3つの力

  1. 式を導く力：オイラー法・ホイン法・RK4の更新式、1階連立への変換、ヤコビアン、線形化。公式を覚えるだけでなく、微分の定義やテイラー展開から再現できるようにする。
  2. 次数と安定性を説明する力：1ステップ誤差と積算誤差の区別、|1 + kΔt| や τ2 = 4Δ の意味。数値ではなく言葉で説明できるかが問われる。
  3. 状態空間で解釈する力：固定点、閉軌道、サドル、センター、スパイラルを、実際の振り子やバネの動きに対応づける。

よくある減点

  • 1ステップ誤差と積算誤差を混同する（オイラー法は O(Δt2) と O(Δt) の両方を書く）。
  • 増幅率の絶対値で安定性を判定せず、符号だけで判断する。
  • θ = π と θ = −π を別の固定点として数える（周期変数なので同一）。
  • センターを「安定」とだけ書く（正しくはリアプノフ安定だが吸引的でない、中立安定）。
  • RK4で成分ごとに段階の違う値を使ってしまう。

復習の優先順位

  1. 演習1の(1)〜(7)：振り子の運動方程式、1階連立、オイラー法・RK4、エネルギー保存による検証、1次精度の説明、相図の解釈。配点の中心になる。
  2. 第9〜10回：ヤコビアン、固有値、τ–Δ 平面による分類。
  3. 第11回：PD制御の安定条件と臨界減衰。制御の極と固有値が同じものであること。
  4. 第12回：ニュートン法（1次元と連立）、ガウスの消去法の流れ。
  5. 第1〜6回：誤差の4分類、モデル化の考え方。短答で出やすい。
