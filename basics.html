期末試験 最小限ここだけ

全部覚える必要はありません。まず前提の3つを押さえ、次に10個だけ手で書けるようにします。 細かい問題演習は最後に回してください。

STEP 1前提: この3つが分かれば全体が読める

  1. 微分 = 変化の割合。 dx/dt は「その瞬間に x がどれだけ増えるか」。だから少し進んだ値は x(t + dt) ≈ x(t) + dt · (dx/dt)。
    オイラー法はこの1行そのものです。公式を暗記する対象ではありません。
  2. 2階微分 = 加速度。状態を2つに分ければ1階になる。 x'' + c x' + k x = u は、位置 x1 = x と速度 x2 = x' の2本の1階方程式に分けられます。
    「1階連立化」と呼ばれる作業はこれだけ。最高階について解いて、m で割るのを忘れないこと。
  3. 固有値 = 向きごとの伸び縮み。 A w = λ w の λ。λ が負なら縮む（戻る）、正なら伸びる（離れる）、純虚数なら回る。
    固定点の分類は、この「戻る・離れる・回る」を λ で言い換えただけです。

STEP 2暗記は10個だけ

  1. 誤差は4種類。丸め（有限桁で表す）／打ち切り（有限回で切る）／情報落ち（大きい数＋小さい数）／桁落ち（近い値の引き算）。
  2. 有効桁は 7 と 16。float32 が約7桁、float64 が約16桁。Python のべき乗は **（^ は別物）。
  3. 前進オイラー: x[n+1] = x[n] + dt·f(t[n], x[n])。1次精度（誤差は dt に比例）。
  4. ホインは2次、RK4は4次。RK4 の重みは (k1 + 2k2 + 2k3 + k4)/6。dt を 1/10 にすると誤差は 1/10、1/100、1/10000。
  5. 安定条件: |1 + k·dt| ≤ 1、つまり dt ≤ 2/|k|（k<0）。後退（陰）オイラーは k<0 なら刻み幅によらず安定。
  6. 2階 → 1階: x1 = x、x2 = x'、dx2/dt = (u − c·x2 − k·x1)/m。
  7. 1次元の固定点: f'(x*) < 0 なら安定、> 0 なら不安定、= 0 は判定不可（半安定があり得る）。
  8. 2次元の固定点: τ = tr(A)、Δ = det(A)。Δ<0 は鞍点。Δ>0 なら τ<0 で安定、τ>0 で不安定、τ=0 で中心点。τ²−4Δ<0 なら渦状点。
  9. ニュートン法: x ← x − f(x)/f'(x)。連立なら J δ = −f を解く（マイナスを落とさない）。
  10. 線形代数: ピボット選択は「ゼロ除算の回避」と「丸め誤差の拡大防止」。LU分解は b が変わっても代入だけで O(n²)。逆行列は solve の約3倍かかるので使わない。

STEP 3混同しやすい組だけ、違いを1行で

組違い
丸め / 打ち切り丸めは「数の表し方」の限界。打ち切りは「計算を途中でやめる」こと。
情報落ち / 桁落ち情報落ちは足し算で小さい側が消える。桁落ちは引き算で有効数字が消える。
陽 / 陰（後退）陽は既知の値だけで次を出す。陰は次の値自身を含む式を解く。陰のほうが安定。
安定 / 漸近安定安定は「離れていかない」。漸近安定は「最終的に近づく」。中心点は安定だが漸近安定ではない。
中心点 / 渦状点固有値が純虚数なら中心点（回り続ける）。実部が負の複素数なら渦状点（渦を巻いて近づく）。
鞍点 / 結節点Δ<0 は必ず鞍点。Δ>0 で τ²−4Δ>0 なら結節点（回らずに近づく・離れる）。
θ = π と −π角度は 2π 周期なので同じ1点。固定点を2個と数えると減点。
1ステップ誤差 / 積算誤差1ステップは O(dt^(p+1))、それを T/dt 回積むと O(dt^p)。次数の言い間違いに注意。
倒立振り子 / 普通の振り子真上基準は重力項が +、真下基準は −。符号を逆にすると制御が倒れる向きに働く。
